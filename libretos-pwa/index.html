Libretos

Abra un libreto en Markdown y léalo en el teléfono. En modo voz el texto avanza a medida que usted lo lee en voz alta.

Pegar libreto
Abrir desde un enlace Sirve con enlaces de GitHub o de GitHub Pages. Los de Google Drive no se pueden leer así: descargue el archivo y use «Abrir archivo .md».
    Cómo lee el libreto. Cada **[E07]** se muestra como inicio de escena; / y // aparecen como pausas en azul; la negrita sale en naranja; las líneas *En pantalla: …* se muestran pequeñas y se pueden ocultar. La tabla «Cómo leer este libreto» se omite.

    Modo voz: siga leyendo y el texto se mueve solo; si repite una frase para corregir la toma, el lector vuelve con usted. Necesita internet y permiso de micrófono. Modo automático: avanza a un ritmo fijo, con 1 s de silencio al inicio de cada escena. Toque una palabra para continuar desde ahí.
    SILENCIO 1 s
    0:00

    Ajustes de lectura

    Teclado o control Bluetooth: espacio inicia o pausa · ← → cambian de escena · ↑ ↓ mueven unas palabras · + − cambian el ritmo · Esc vuelve.

    Escenas

    «~» es lo estimado para el libreto. En naranja, lo que tardó en leer cada escena seguida en esta sesión.
